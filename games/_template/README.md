# Modèle d’un nouveau jeu

Copier ce dossier vers `games/nom-du-jeu/` et remplacer les textes. Le point d’entrée `index.html` doit pouvoir s’ouvrir en direct pour les essais, puis être relié à un jeu du jour dans une ligue Rivo. Mettre les règles dans `game.js`, l’affichage dans `app.js`, et les réglages ensemble. Prévoir une pause, une fin de manche et un bouton Rejouer. Ajouter un test des règles dans `tests/`. Garder l’accueil principal centré sur les ligues.

La convention commune est décrite dans `docs/game-contract.md`. C’est une cible d’intégration, pas une bibliothèque obligatoire pour les prototypes.
